# JW Tree Work

Marketing site for JW Tree Work Inc., a tree service company in Florida — services,
gallery, and a quote request form.

**Live:** https://jw-tree-work-umgt.vercel.app

## Built with

Next.js and TypeScript, deployed on Vercel.

## Running it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

```bash
npm run build
```
